Status: Active implementation inventory

## Completion rule

A row is complete only when web renders authoritative state, invokes the same
business transition as mobile, covers pending and terminal outcomes, preserves
context across navigation and reload, and has Playwright evidence at narrow and
desktop widths. A route existing or compiling is not parity evidence.

## Intentionally non-identical surfaces

- Drapeon Vision camera capture remains native. Web explains and opens the native handoff while web measurement management remains complete.
- Native biometric unlock, native push permission UI and device camera editors are not copied into web. Web uses secure sessions, Web Push where supported and browser-appropriate file and media editing.
- Layout is responsive and desktop-native. Behavioral and domain parity does not require pixel-for-pixel mobile duplication.
